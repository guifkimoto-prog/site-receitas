# Minhas Receitas

Site de receitas feito para a disciplina de **Interfaces Web I** (Prof.ª Juliana de Sá), usando HTML, CSS e Bootstrap 5.

## Páginas

- **index.html** – página principal com a listagem das receitas
- **receitas/** – uma página para cada receita, com ingredientes, materiais, modo de preparo, tempo, dificuldade, rendimento e um formulário de comentários

## Receitas

1. Bolo de Cenoura
2. Macarronada
3. Pudim de Leite Condensado
4. Queijo Quente
5. Escondidinho de Carne Seca
6. Lasanha à Bolonhesa

## Estrutura

```
├── index.html
├── receitas/
├── css/style.css
├── js/comentarios.js
└── img/
```

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5.3 e Bootstrap Icons
- JavaScript (para salvar os comentários no navegador)

## Como abrir

Basta abrir o arquivo `index.html` no navegador.
